# Internationalisation

Les traductions reposent sur [Transloco](https://jsverse.gitbook.io/transloco) et le format de messages ICU (`@jsverse/transloco-messageformat`) pour les pluriels.

## Langues

| Code | Langue | Statut |
|---|---|---|
| `fr` | Français | **Référence** : langue par défaut et langue de repli |
| `en` | Anglais | Complète |
| `es` | Espagnol | Complète |
| `it` | Italien | Complète |

Les quatre fichiers `src/assets/i18n/<code>.json` contiennent exactement les mêmes clés (271 au moment de la rédaction). Ils sont chargés à la demande par `TranslocoHttpLoader` (chemin relatif `assets/i18n/<code>.json`, compatible Capacitor).

## Configuration

| Où | Rôle |
|---|---|
| `src/app/transloco-root.module.ts` | `AVAILABLE_LANGS`, langue par défaut et de repli (`fr`), `missingHandler.useFallbackTranslation` (une clé absente dans une langue affiche le texte français plutôt que la clé brute), `failedRetries: 1` |
| `src/app/core/types/LanguageConfig.ts` | Nom natif, nom anglais et drapeau de chaque langue (écran de choix de la langue) |
| `transloco.config.ts` | Configuration des outils en ligne de commande Transloco (`langs`) |
| `PreferencesService` | Mémorise la langue de l'appareil, charge la traduction avant de l'activer, met à jour `<html lang>` |

La langue est un **réglage de l'appareil** (non synchronisé avec le compte). Au premier lancement, c'est le français.

## Conventions

- **Clés** : `SECTION.SOUS_SECTION.CLE` en majuscules ; une section par écran ou composant (`SETTINGS.CAVE.DISPOSITION.MODAL.SAVE`). Les textes communs vont dans `COMMON.*`, les messages d'erreur génériques dans `ERRORS.*`.
- **Variables** : `{{nom}}` (ex. `"Bienvenue, {{prenom}} !"`). Le nom de la variable doit être identique dans toutes les langues.
- **Pluriels** : syntaxe ICU. Dans un bloc `plural`, la valeur du nombre s'écrit `{{count}}`, comme dans les textes existants :

  ```json
  "BOTTLES_FOUND": "{count, plural, =0 {0 bouteille trouvée} =1 {1 bouteille trouvée} other {{{count}} bouteilles trouvées}}"
  ```

  Chaque langue doit fournir les mêmes branches (`=0`, `=1`, `other`) — voir plus bas.
- **Registre** : le français s'adresse à l'utilisateur au **vouvoiement** ; les autres langues utilisent la forme de politesse courante des applications grand public (tutoiement en espagnol et en italien, « you » en anglais).
- **Aucun texte en dur** dans les gabarits ni dans le code : tout passe par une clé. Les erreurs sont traduites par la couche d'interface (`toErrorKey`).
- Les clés dynamiques (`SETTINGS.CAVE.DISPLAY.GRID` / `LIST`, `WINE.TYPE.*`, `WINE_SHEET_MODAL.RATING_MODAL.LABEL_*`) sont construites à l'exécution : ne pas les supprimer même si une recherche textuelle ne les trouve pas.

## Ajouter une clé

1. Ajouter la clé et son texte dans **`fr.json`**.
2. Ajouter la même clé, avec la traduction, dans `en.json`, `es.json` et `it.json` (au même endroit de l'arborescence, pour garder les fichiers comparables).
3. Utiliser la clé dans le code (`'MA.CLE' | transloco` ou `this.transloco.translate('MA.CLE')`).
4. Lancer `npm run check:i18n`.

## Ajouter une langue

1. Créer `src/assets/i18n/<code>.json` en copiant `fr.json` et en traduisant toutes les valeurs.
2. Ajouter le code à `AVAILABLE_LANGS` (`transloco-root.module.ts`) et à `langs` (`transloco.config.ts`).
3. Ajouter l'entrée correspondante dans `LANGUAGE_CONFIG` (`LanguageConfig.ts`) et déposer le drapeau dans `src/assets/flags/flag_<code>.svg`.
4. Lancer `npm run check:i18n`.

## Contrôle automatique : `npm run check:i18n`

Le script `scripts/check-i18n.mjs` (exécuté par la CI) échoue si :

- une langue a une clé en moins ou en trop par rapport à `fr.json` ;
- une valeur est vide ;
- les variables `{{…}}` d'une clé diffèrent de celles du français ;
- la structure des pluriels (variable et branches `=n` / `other`) diffère ;
- une clé littérale utilisée dans `src/app/**` n'existe pas dans `fr.json`.

Il ne vérifie pas la qualité linguistique : une relecture par un locuteur natif reste recommandée pour `en`, `es` et `it`.

## Particularités par langue

Le pluriel ICU de Transloco suit les règles de la langue (`one` / `other`…). Les textes de Vinum n'utilisent que `=0`, `=1` et `other`, valables pour les quatre langues actuelles. Pour une langue à pluriels plus riches (russe, arabe, polonais…), il faudra ajouter les catégories nécessaires (`few`, `many`) dans **toutes** les clés `plural` de cette langue.
